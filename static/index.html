What is this?

robot.wtf gives you a wiki backed by a git repo of Markdown files. There's a web UI for reading and editing, and an MCP endpoint so AI agents can use it too. Every wiki lives at yourname.robot.wtf.

This started as a research tool. I needed a place where I could dump notes and have my AI assistant organize them later. Existing wikis didn't have good agent access, and existing agent memory tools didn't have good human access. So I built this.

It runs on An Otter Wiki, an open-source wiki engine. The platform layer handles accounts, multi-tenancy, and the MCP integration. The whole thing is a volunteer project — there's no company, no funding, no business model.

How it works

  1. Sign in with Bluesky. Your Bluesky handle becomes your identity. No new account to create.
  2. Create a wiki. Pick a slug, get yourslug.robot.wtf with a web editor and full-text search.
  3. Copy the MCP URL. Point Claude Desktop, Cursor, or any MCP client at your wiki's endpoint.
  4. Write. You and your agents edit the same Markdown pages. Changes are versioned in git.

FAQ

What's MCP?

Model Context Protocol is an open standard that lets AI agents use external tools. Your wiki exposes MCP tools for reading, writing, and searching pages. When you give an agent your wiki's MCP URL, it can look things up and take notes without you copy-pasting anything.

Is it free?

Yes. robot.wtf is a volunteer project. There are no paid tiers, no ads, no data harvesting. If running costs become a problem, I'll figure it out then.

What agents work with it?

Anything that speaks MCP. Claude Desktop, Claude Code, Cursor, Windsurf, and the list keeps growing. If your tool can connect to an MCP server, it can use your wiki.

Can I git clone my wiki?

Not yet. Each wiki is a bare git repo on the server, and exposing git-over-HTTP is on the roadmap. For now, you can use the web UI or MCP tools to read and write pages.

What about privacy?

Wikis are private by default. Only you and people you explicitly grant access to can read or edit. The MCP endpoint uses OAuth, so agents authenticate before they can do anything. Your data lives in a git repo on the server — it's not fed to any AI model.

Why Bluesky?

ATProto has decentralized identity built in. Your @handle is already a verified identity, so there's no need for yet another username/password. It also means this project is useful to the community that's actually building on the protocol.
